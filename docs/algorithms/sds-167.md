# SDS over Z_167

Secondary target: Goethals-Seidel construction over `Z_167`.

## Current implementation

- exact enumeration of the 10 feasible `(k1, k2, k3, k4; lambda)` parameter sets forced by the row-sum square constraint
- CLI exposure through `hadamard enumerate sds-167`
- cyclic SDS block representation and difference-profile math
- shardable meet-in-the-middle SDS search scaffold, currently exercised on a small `Z_5` instance via `hadamard search sds --order 5 --block-sizes 2,2,0,0 --lambda 1`
- Goethals-Seidel construction from four complementary cyclic sequences or a suitable four-block SDS, checked on a `Z_5 -> HM(20)` fixture

## Planned scaling work

- shared artifact/checkpoint support with the LP track
- a production `Z_167` search that does not materialize full block pools
- stochastic or exact-orbit search with independently checked final artifacts
